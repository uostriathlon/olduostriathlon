# University of Sheffield Triathlon Club Website

Static export of the club website, prepared for GitHub Pages.

## Deployment

1. Create a new GitHub repository.
2. Push the contents of this folder (not the folder itself) to the `main` (or `gh-pages`) branch.
3. In repository Settings → Pages, set Source to the branch and root (or `/docs` if preferred).
4. The site will be available at `https://<username>.github.io/<repo>/`.

## Notes

- Original site was built with Wix. Some external assets (fonts, analytics, Facebook plugins) still load from third-party CDNs and may require network access.
- Local images and structure have been cleaned for static hosting.
- Broken/missing Wix font files were removed; the browser will fall back to system fonts.
- Image filenames containing spaces or percent-encoding were normalized.
- Duplicate "copy-of-*" pages retained for archival completeness.
